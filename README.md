## 🥊 Acerca de GLADIADORES MMA

**GLADIADORES MMA** es la academia líder en enseñanza y entrenamiento de Artes Marciales Mixtas en Coatzacoalcos, Veracruz. Nuestro programa está diseñado para niños, jóvenes y adultos, combinando técnica de alto rendimiento, disciplina marcial y acondicionamiento físico integral con entrenadores profesionales acreditados por la Federación Nacional.

> *"No solo somos una academia, somos una familia marcial."*

---

## ✨ Características de la Plataforma Web

- ⚡ **Arquitectura Moderna:** Desarrollada con React 19, TypeScript y Vite para una experiencia de usuario ultra rápida.
- 🌓 **Soporte Light / Dark Mode:** Selector de tema en el Navbar con persistencia en `localStorage`.
- 📱 **Diseño 100% Responsivo:** Adaptado a pantallas móviles, tablets y monitores de escritorio mediante Tailwind CSS.
- 🛡️ **Optimizada para cPanel:** Integración con `.cpanel.yml` y `.htaccess` preconfigurado con compresión Gzip, expiración de caché y soporte completo para navegación SPA (Single Page Application).
- 🥋 **Secciones Informativas:**
  - **Nosotros:** Metodología y filosofía del sistema 100% MMA.
  - **Head Coach:** Trayectoria del Head Coach Frank Hernández Medel.
  - **Horarios y Clases:** Programas infantiles, juveniles y para adultos.
  - **Galería:** Registro fotográfico de entrenamientos y competencias.
  - **Prensa:** Cobertura de medios y logros de nuestros atletas.
  - **Contacto:** Enlace directo de atención vía WhatsApp.

## 💻 Desarrollo Local

Para ejecutar el proyecto en tu entorno local:

```bash
# 1. Clonar el repositorio
git clone https://github.com/Willy100fuegos/gladiadorescoatzacoalcos.git

# 2. Ingresar al directorio
cd gladiadorescoatzacoalcos

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev
```

---

## 🚀 Compilación y Despliegue

Para generar los archivos listos para producción:

```bash
npm run build
```

El build se compila dentro de la carpeta `out/`, la cual es gestionada automáticamente por cPanel mediante `.cpanel.yml` para desplegarse en `public_html`.
